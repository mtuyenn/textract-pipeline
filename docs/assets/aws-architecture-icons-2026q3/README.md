# AWS Architecture Icons used in the project diagram

These selected PNG assets are official AWS Architecture Service and Resource Icons from the Q3 2026 icon package. The AWS icon page provides these assets for creating architecture diagrams and related technical materials.

- Official page: https://aws.amazon.com/architecture/icons/
- Package: Icon-package_07312026
- Icons used: Amazon S3, AWS Lambda, Amazon Textract, Amazon DynamoDB, Amazon EventBridge, Amazon SNS, Amazon CloudWatch, and Amazon VPC.
- The diagram layout, labels, connectors, colors, and explanatory notes were authored for this project.

The AWS service icons identify AWS products; they do not imply that every resource has been verified live in the same account. The architecture diagram separates the Week 1 VPC from the CloudFormation stack because the template does not create a VPC and the Lambda functions are not attached to it.
